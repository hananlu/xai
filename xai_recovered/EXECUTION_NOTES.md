# Execution notes

- Recovery copied original Drive downloads into `recovered/` without executing them. No missing-laptop access is assumed.
- The initial verification assertion used integer datetime values with an assumed nanosecond unit. The installed pandas uses a different resolution. The assertion failed before baseline/model fitting; it was corrected to use explicit `dt.total_seconds()`. The data preparation and segment policy were unchanged. All validation assertions then passed.
- Python 3.11 was used in an isolated workspace virtual environment. Dependencies came from the standard package registry. Exact versions are locked.
- A synthetic ten-step benchmark gave approximately 0.043 seconds/CPU step versus 0.218 seconds/MPS step for batch 256, 144 lags, hidden size 32. CPU was selected for throughput, without looking at test performance.
- Protocol and implementation were written before new model training. Historical result outputs remain separate from new metrics.
- After observing the initial baseline results, an **exploratory post-hoc** exact Ridge decomposition was added in `src/explore_ridge.py`. It introduces no fitting, tuning or extra performance claim. Contributions are conditional fitted linear contributions relative to the training mean; they are not causal effects. The primary protocol and its hashes remain unchanged.
- While primary training was still in progress, a secondary **residual-path diagnostic** was added to analysis. Since attention covers pooled hidden states but IG covers the full residual model, we subtract the exact linear skip attribution to obtain correction-only IG and report correction-only perturbation shifts using the original rankings. This prevents a computational-scope mismatch from being mistaken for proof that attention fails on its own branch. The added diagnostic is explicitly identified as secondary in the manuscript; it does not change fitting or replace the primary audit.
- The planned 32/64-interval IG checks showed large completeness residuals in some cases. A **secondary numerical follow-up** at 128/512/2,048 intervals on the same first 16 fixed origins per model/seed was therefore added. Original IG outputs are retained, and IG-based rankings/comparisons are marked provisional; no claim of superiority over a validated IG reference is made. This is a disclosed numerical limitation, not a hidden change to the training protocol.

- Editorial revision after user feedback expanded the bibliography from 8 to 26 cited works, completed publication metadata, added a literature comparison table and clarified the exact recovered data files. This does not change the frozen protocol, fits, predictions or numerical claims.
