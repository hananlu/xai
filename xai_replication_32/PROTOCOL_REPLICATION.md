# Frozen new-target replication protocol — 6 November 2026

This protocol is written after inspecting the original 8-target CESNET study, and before forecasting/explanation performance is evaluated at the additional target institutions. It is a prospectively frozen new-target cohort within the same ISP, not an external preregistration, a new network, or an independent training run. The original primary result and its paper remain intact. The source forecasters, source anchors and selected hyperparameters are reused. No preferred direction or significance is required.

## Cohort and membership

Use the pre-existing 2024-only institutional audit. Exclude all 48 original-study institutions and all 12 earlier development institutions from new target membership. Reconstruct the four original equal-count 2024 median-volume strata over the 265 eligible non-development institutions; verify the known membership strata agree exactly. Of the 217 remaining candidates, take the first eight per stratum under SHA256 of `xai-replication-32-20261106-v1:{id}`. This yields 32 new targets. No target forecast errors, attribution scores or later availability enter membership. Do not replace unavailable or non-discriminating institutions after evaluation.

Use all 32 locked source-training institutions as anchors. Within each original volume stratum, match its eight source anchors to eight new targets one-to-one by Hungarian minimum total distance. Descriptors are 2024 log1p median GB and log1p(std/median), standardized by the eight source descriptor standard deviations (constant dimension scale=1). Matching is descriptive and has no causal identification interpretation or post-result caliper. Keep all matching distances.

Keep source model/profile files byte-identical to the original locked model set: Ridge, DLinear and GRU, neural seeds42/123/2026; no retraining, new normalization, learning-rate selection or architecture changes. Validation selection remains the original eight validation institutions. New targets never enter model fitting. `MEMBERSHIP_FREEZE.json` records membership, exclusions, model hashes and chronology.

Match source and target explanation timestamps within each fixed pair/year using availability only. For the main replication budget select up to16 evenly spaced common eligible origins, with up to4 evenly spaced of those for IG. Retain absent pair-years and every undefined score.

No claim that replacements are natural conditional traffic draws.

## Main replication endpoint

Frozen GRU, h1, source-calendar Shapley Q, target-minus-source. Require all three neural seeds defined before seed averaging; pair source/target at identical origins and operators. Average within pair/year/operator, equally over both years and operators, then equally over complete pairs. A pair must have data in all four cells; missing pairs remain excluded with explicit reasons. Do not pool original and new target cohorts as independent replications: anchors/models overlap. Compare their estimates descriptively with that overlap disclosed.

Primary uncertainty uses the exact original 2,000 attempted paired-pair/within-pair14-day-block bootstrap and random seed20261105 for direct protocol replication. Draws missing an operator cell are invalid and counted. Report a nominal percentile95% interval only with >=4 complete pairs and >=1,000 valid draws; otherwise report the point and interval failure. Do not increase the draw budget/tolerance after outcomes. Targeting32 pairs does not guarantee32 complete pairs; do not interpret a larger case count as independent replication. Scope is the eligible complete-pair panel, conditional on the fixed trained model, within one ISP. A narrow interval is not guaranteed and no equivalence/non-inferiority margin is defined.

## Prespecified uncertainty and sampling sensitivity

1. **Pair-only cluster bootstrap:** 2,000 resamples of the complete per-pair four-cell means, seed20261106. This conditions on the observed evaluation periods; it does not estimate new-time-period uncertainty. It is secondary, not a replacement for a failing primary interval.
2. **Synchronized calendar-block bootstrap:** 2,000 attempts, seed20261106. Resample complete pairs and one shared set of 14-day block labels per year, from all six calendar blocks0..5. Apply the same sampled time blocks across selected pairs/operators to preserve common calendar shocks. Require every selected pair/year/operator to have sampled valid data. Invalid draws are counted; require>=1,000 valid draws for a nominal percentile interval. Report failure without changing rules. This is a prespecified sensitivity, not a guaranteed correct dependence model.
3. **Denser origin budget:** frozen GRU only, same source-calendar reference, both horizons and both operators, Shapley/occlusion/recency, all three seeds. For each pair/year retain the main16 origins; add up to48 evenly spaced indices from the remaining common eligible origins, for up to64 total. If fewer available, retain all and report the actual size. This nesting uses only timestamps/availability. IG and calibration are not extended to the dense budget. Reuse identical main-budget rows; compute only added cases. Recompute complete-seed paired point/interval with the same original bootstrap rule. Report main-vs-dense estimates and intersection-case equality. If complete-pair panels differ between budgets, also report their common-complete-pair comparison to distinguish sampling density from panel composition; do not select a preferred budget after outcomes.

Other models/references, calibration changes, per-year differences, common accepted IG comparisons, zero/undefined cases and method/seed stability are secondary exploratory descriptions without multiplicity correction. No winning secondary endpoint is promoted to a primary claim.
